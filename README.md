## ✨ Key Features

| | |
| --- | --- |
| 🎬 **3D Product Showcase** | Isolated cut-out renders staged on floating gradient platforms with layered contact shadows for a true dimensional feel. |
| ✨ **Pastel Stage System** | 8 engineered mood surfaces — cream, lavender, mint, powder, peach, sage, butter & rose — each with its own gradient depth and light quality. |
| 🎞 **Fluid Motion Design** | Motion-powered reveals, scroll parallax, magnetic hover effects and spring physics throughout the whole journey. |
| 🛍 **Full Commerce Flow** | Slide-out shopping bag, saved-collection wishlist, live search overlay and product detail modal with color variants. |
| 🗂 **Curated Catalog** | 20 signature pieces — sofas, armchairs, lighting & more — each with color variants, artisan materials and editorial stories. |
| 🖌 **Artisan Typography** | Soft clay 3D type treatments, embossed headlines and a refined Fredoka × Outfit Sans pairing. |
| ⚡ **Modern Stack** | React 19 · TypeScript 5.8 · Vite 6 · Tailwind CSS 4 · Motion 12. |

## 🚀 Quick Start

**Prerequisites:** Node.js 18+

```bash
npm install
npm run dev        # → http://localhost:3000
```

| Command | Purpose |
| --- | --- |
| `npm run build` | Production build → `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | Type check with `tsc --noEmit` |

> ✨ The shopping bag and saved collection ship pre-seeded, so every stage of the journey — browse → detail → checkout — is alive on first load.

---

## 🛠 At a Glance

- **Catalog:** edit [`src/data/products.ts`](src/data/products.ts) to add pieces — each supports its own story, artisan material, dimensions, color variants, stage gradient and imagery.
- **Sections:** every stage of the showroom lives in [`src/components/`](src/components/) — hero stage, featured gallery, category surfaces, carousels, editorial spreads, cart, wishlist and search.
